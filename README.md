## ✨ Fonctionnalités

### 📅 Planning partagé
- **Un planning par groupe**, jour par jour et semaine par semaine, avec une colonne par membre.
- Créneaux **⛔ Occupé** et **✅ Disponible**, répétables chaque semaine (pratique pour un emploi du temps de cours).
- Une colonne **« ✓ Tous libres »** calcule automatiquement les moments où personne n'est occupé.

### 🎉 Sorties
- Propose une sortie : **quoi, où, pourquoi, quand, de quelle heure à quelle heure** et, si tu veux, un **budget par personne**.
- L'app te suggère les **créneaux où tout le groupe est libre** ce jour-là.
- Chacun répond **✅ Partant, 🤔 Peut-être ou ❌ Non**, et on voit qui n'a pas encore répondu.

### 💬 Messagerie
- **Chat de groupe** pour chaque groupe et **messages privés** entre amis.
- Envoi de **photos et vidéos**, affichées en plein écran.
- Pastille de **messages non lus**.

### 🔒 Vie privée et personnalisation
- **Protège une conversation ou un groupe par un code** de 3 à 6 chiffres : reste appuyé 2 secondes dessus. Le code est demandé à chaque ouverture.
- **Surnoms** pour tes amis, visibles par toi seul.
- **Photo de profil ronde** avec recadrage.
- **Contacts récents** proposés quand tu crées un groupe.

### 👥 Comptes et groupes
- Compte avec une **adresse mail** et un mot de passe, avec réinitialisation par mail.
- **Ajoute quelqu'un par son mail.** S'il n'a pas encore de compte, il rejoint le groupe automatiquement à son inscription.

## 📲 Installer Dispo

| Appareil | Comment |
|---|---|
| **iPhone** | Ouvre [dispo-e67a7.web.app](https://dispo-e67a7.web.app) dans **Safari**, puis **Partager → « Sur l'écran d'accueil »**. |
| **Android** | Ouvre le lien dans Chrome puis **⋮ → « Ajouter à l'écran d'accueil »**, ou installe l'APK. |
| **Ordinateur** | Ouvre simplement [dispo-e67a7.web.app](https://dispo-e67a7.web.app). |

Tout le monde partage les mêmes comptes, groupes et messages, quel que soit l'appareil.

## 🛠️ Technologies

| | |
|---|---|
| Application | [Expo](https://expo.dev) / React Native (une seule base de code pour Android, iOS et le web) |
| Comptes | Firebase Authentication (mail + mot de passe) |
| Données en temps réel | Cloud Firestore, protégé par des règles de sécurité |
| Photos et vidéos | Cloudinary |
| Hébergement web | Firebase Hosting |
| Application Android | EAS Build (fichier APK) |

Aucun serveur à faire tourner : tout est hébergé dans le cloud.
